# Tangkapan layar permintaan client

Gambar yang dikirim client dan leader lewat WhatsApp, disalin ke sini supaya
tidak ikut hilang saat percakapan dipadatkan atau folder sementara dibersihkan.

Asalnya folder sementara per sesi di
`%LOCALAPPDATA%\Temp\claude\d--Kasir-Danang\<id-sesi>\images\`. Folder itu
berumur pendek dan berganti tiap sesi, jadi bukan tempat menyimpan.

Nama berkas: `TANGGAL_NOMOR.png`, tanggal diambil dari waktu berkas dibuat.

## Aturan

Tiap kali client atau leader mengirim tangkapan layar berisi permintaan,
salin ke sini dan tambahkan barisnya di tabel di atas, lalu tautkan dari
butir yang bersangkutan di `PERMINTAAN-CLIENT.md`.
